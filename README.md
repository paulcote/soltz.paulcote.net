# Solar Noon in Canada / Midi solaire au Canada

An interactive map of how far solar noon falls from 12:00 on the clock, across Canada. Pick a day of the year, then compare the current rules with daylight time all year or standard time all year.

Live site: <https://soltz.paulcote.net> (French by default, English with `?lang=en`).

## Features

- Smooth colour gradient: clock time of solar noon minus 12:00, per time zone. Brown lines mark zone boundaries.
- A black line where solar noon falls exactly on 12:00.
- Hover the map for sunrise, solar noon, sunset, day length and offset at that point.
- Year slider with markers for solstices, equinoxes and the DST changes.
- Three modes: current rules, daylight time all year, standard time all year.
- "Recent changes" option (on by default): British Columbia (UTC−7), Alberta (UTC−6), Manitoba (UTC−5) and the Northwest Territories (UTC−6) stay on permanent daylight time in every mode.
- City comparison table, grouped by region and ordered west to east.
- French and English. The language is in the URL (`?lang=en`); date, mode and option are in the hash (`#date=2026-01-15&mode=std&recent=0`), so any view can be shared.
- A [sources page](sources.html) describing where the data and calculations come from.

## How it works

Everything runs in the browser; there is no backend.

- **Solar times:** [SunCalc](https://github.com/mourner/suncalc). Solar noon is computed per longitude for the gradient, and at the exact cursor position for the tooltip.
- **Clock time:** each province is rasterised once and assigned a time zone (`src/tz.ts`, `src/zones.ts`). The UTC offset of a zone depends on the mode, the date and the "recent changes" option.
- **Rendering:** the gradient is drawn on a canvas and shown as an image layer in [MapLibre GL JS](https://maplibre.org/), over a vector basemap. The noon line is a GeoJSON layer.
- **Season markers:** equinox and solstice dates use Meeus's algorithms (`src/astro.ts`).

Time zone boundaries are approximate, and small enclaves are ignored. Values are indicative and can differ by a few minutes from official almanacs.

## Development

Requires Node 22 or later.

```sh
npm install
npm run dev       # http://localhost:5173
npm test          # unit tests (vitest)
npm run build     # typecheck + production build into dist/
npm run preview   # serve dist/ locally
```

### Basemap

The basemap style and tiles come from a tile server, set in `src/main.ts` (`TILE_ORIGIN`). The server must send CORS headers for the origins that load the site. In development, requests go through a Vite proxy (`/tiles`, see `vite.config.ts`), so no CORS setup is needed locally. To use another OpenMapTiles-compatible style, change `STYLE_URL`.

### Project layout

| Path | Purpose |
| --- | --- |
| `src/main.ts` | Map, controls, tooltip, table, URL state |
| `src/tz.ts` | Zones, DST rules, UTC offset by mode |
| `src/zones.ts` | Province raster and zone lookup |
| `src/gradient.ts` | Colour ramp, gradient canvas, noon line |
| `src/solar.ts` | Sunrise, solar noon, sunset, clock formatting |
| `src/astro.ts` | Solstices, equinoxes, DST change dates |
| `src/cities.ts` | Cities and regions for the table |
| `src/i18n.ts` | French and English strings, language switching |
| `public/data/canada.geojson` | Simplified province boundaries |
| `public/og-image.png` | Social preview image (1200×630) |
| `sources.html` | Data sources page |

### Adding a region with permanent time

Add a zone in `src/tz.ts` with `permanentDst: true` (its `std` offset is the standard-time one), map the province to it in `zoneIdAt`, and add its label in `src/i18n.ts`.

## Deployment

The site is deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`. The workflow runs the tests, builds, and publishes `dist/`.

- Set Settings → Pages → Source to **GitHub Actions**.
- `public/CNAME` holds the custom domain.
- `VITE_SITE_URL` in `.env` is the public URL used for canonical links and `og:image`. Change it if the domain changes.
- The preview image `public/og-image.png` is a static picture and has to be regenerated by hand if the map's look changes.
